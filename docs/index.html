文件留在你的手机里

PDF，小一点。
隐私，留身边。

选择文件，在浏览器内完成压缩。无需登录，不上传 PDF。

选择一个 PDF

建议单个文件不超过 30MB、100 页。

优先将画质预算分配给这些页面；手机仍有内存上限，未必能达到电脑效果。

用百分比框选人脸或二维码。多个区域用英文分号隔开。

手机本地版会转为整页图片：保留页面顺序与显示方向；文字无法复制，链接、表单和数字签名功能会丢失。印章、小字和二维码请复核，不保证所有文件都能达标。

首次打开需要联网加载组件，PDF 内容不会发送到网络。

备用方式：直接下载 PDF

在系统分享面板选择“存储到文件”或文件管理器。备用下载若跳入 blob 空白页，请返回，在 Chrome / Edge / Safari 中重新打开本工具；部分手机内置浏览器不支持本地文件下载。不要复制 blob 地址，它不是网络下载链接。请放大复核并扫码验证。

文件只在当前浏览器内存中处理，刷新页面即清除。
首次访问仍会向 GitHub Pages 请求网页与程序组件。
